# Enemy catalog and prediction coverage

**Historical coverage:** the Wacky/MM expansion described below was rolled back at the user's request. The live controller no longer imports this catalog or the broad pattern learner. Targeted Switch activation and bounded Spiral curvature fixes were subsequently added; Sizing/Turning, Slippery, Pumpkin and teleport forecasts remain inactive. See [the current rollback state](pre-wacky-rollback.md); the catalog remains reference data.

[The directory](enemy-types.md) lists 143 enemy types and 88 projectile types extracted from the current public Evades client. [The JSON catalog](../data/enemies.json) includes numeric IDs, default properties, available telemetry schemas, the source URL, retrieval time and source SHA-256. Player projectiles appear in the directory too; the controller uses live `isEnemy` / `isEnemyProjectile` flags to identify threats.

The live entity's radius, velocity, effects and area boundaries take precedence over defaults. A catalog entry does not mean the server's complete behavior is implemented. Generic telemetry schemas only list shared fields. Some special types have no dedicated public schema, and future attacks or newly spawned projectiles cannot be enumerated from the current observation.

The [community enemy guide](https://evadesio.fandom.com/wiki/Enemies) provides readable descriptions, but identifies itself as incomplete. The catalog and phase models here use the [public game client](https://evades.io/index.e75284cc.js), saved in `artifacts/public-client-index.e75284cc.js`, plus recorded game observations. This is browser code with defaults, message schemas and some prediction routines; it is not a complete server implementation.

| Family or property                                                                                         | Controller behavior                                                                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Every live enemy/projectile                                                                                | Retained unless removed or missing a position, including harmless bodies and unknown type IDs.                                                                                                                                                                                                   |
| Normal bodies and Wall                                                                                     | Moving circles/squares, area reflections, and server-tick perimeter corners.                                                                                                                                                                                                                     |
| Dasher                                                                                                     | Preparation, launch, slowing and rest using observed phase data.                                                                                                                                                                                                                                 |
| Homing                                                                                                     | Separate pursuit forecast for each candidate player route.                                                                                                                                                                                                                                       |
| Switch and other harmless states                                                                           | Track through harmlessness; include collisions after the observed timer expires, with one tick of allowance for an early transition. Missing timers are treated as lethal immediately. No unobserved future harmless interval is assumed.                                                        |
| Sizing                                                                                                     | Observed base radius, multiplier and growth direction; predict the public 1.2/second multiplier change and reversal at 0.4/2.5. Collision bounds grow with the body.                                                                                                                             |
| Turning                                                                                                    | Use the client's learned angular rate and direction, including reversal after an outer-zone bounce.                                                                                                                                                                                              |
| Wavy, Zigzag, Spiral, Zoning, Oscillating, Confectioner, Dorito, Penny, Infinity and their Switch variants | Fit angular velocity/acceleration or a repeating velocity cycle from past samples. Repeating fits must agree with newer samples. Good fits use a small error allowance; missing or inconsistent data uses a broader reachable region.                                                            |
| Pumpkin (Haunted Halls)                                                                                    | Ignore stale cached velocity while dormant. Track activation countdown and the remaining 1.5-second charge. During windup, reserve possible launch directions after the countdown because aiming can still change.                                                                               |
| Star (Elite Expanse) and Teleporting                                                                       | Use observed pause time, interval, distance and direction to predict stationary intervals and discrete landings. Star alternates endpoints; Teleporting reflects at outer boundaries. Collision checks include intermediate landings without treating empty space between endpoints as occupied. |
| Liquid, Icicle                                                                                             | Use the uncertainty region. It cannot bound a new acceleration. Exact phase behavior remains incomplete.                                                                                                                                                                                         |
| Slowing, Freezing, Withering                                                                               | Read live aura radii and apply speed effects.                                                                                                                                                                                                                                                    |
| Slippery (Restless Ridge)                                                                                  | Read live aura radius, preserve entry angle while inside, ignore direction changes and Shift braking during the slide, and model recovery after leaving or hitting the outer wall. Coarse navigation adds a cost for entering these fields.                                                      |
| Timed enemy stops/slows                                                                                    | Integrate expiry times; keep a stopped body's collision geometry.                                                                                                                                                                                                                                |

Unmodeled special types still receive a current-velocity body forecast. Force fields, future projectiles, internal-obstacle enemy bounces and teleport collisions, many hero abilities, teammate retargeting and other server mechanics remain incomplete. Learned fits are estimates, not complete server rules; their errors can grow after a phase change. The fallback region is conditional on observed speed and cannot bound arbitrary acceleration or unmodeled teleports. No full Monumental Migration, Wacky Wonderland, Haunted Halls, Restless Ridge or Elite Expanse clear has been verified with this revision.

`src/enemy-motion.js` learns from at most five seconds of past samples per entity. It resets on area changes, long observation gaps and stop/slow effects; rejected fits return to the fallback. Period searches run at most five times per second per entity. Logs count learned forecasts and remaining fallbacks so an unrecognized pattern can be identified in subsequent recordings.

Run `npm run simulate:enemies` for behavior regressions, seeded courses and recorded Wacky encounter comparisons. It writes a per-type coverage inventory to `artifacts/enemy-suite.json`, including types without separate checks. See [simulation scope and extension instructions](enemy-simulations.md). Listing an enemy in the catalog does not mark it as validated.

The [Monumental Migration video reference](monumental-migration.md) maps the supplied run's first 120 areas into enemy-family groups and identifies the remaining MM simulation gaps. Its repeated sequence is a test-organizing reference, not a runtime spawn table.

Refresh from the currently published client:

```sh
python3 scripts/build-enemy-catalog.py
```

Rebuild from the downloaded source used for this revision:

```sh
python3 scripts/build-enemy-catalog.py \
  --source artifacts/public-client-index.e75284cc.js \
  --url https://evades.io/index.e75284cc.js
```

The script parses data literals without executing the downloaded JavaScript. Review numeric IDs and model coverage when updating it. Runtime metadata lives in `src/enemies.js`; the observer, local planner and route planner consume it. Restart the controller after source or catalog changes.
